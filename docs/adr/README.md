# Architecture Decision Records — VitaCerta

Esta pasta registra decisões arquiteturais que precisam sobreviver ao histórico de conversas.

Cada ADR deve conter:

- Status
- Contexto
- Decisão
- Consequências
- O que deve ser preservado em um clone

Numeração: `NNNN-titulo-curto.md`.

O `BLUEPRINT.md` é o índice operacional de reconstrução; os ADRs explicam por que decisões estruturais foram tomadas.
